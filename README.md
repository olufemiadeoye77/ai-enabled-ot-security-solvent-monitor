# AI-Enabled Industrial OT Security and Process Monitoring Platform

## 1. Project Overview

An educational industrial monitoring and defensive OT cybersecurity
platform designed initially for a palm kernel cake solvent-extraction
plant, with planned expansion to edible oil refinery operations.

The platform combines process monitoring, anomaly detection,
cybersecurity event analysis, event correlation, AI-assisted
investigation and operational reporting.

## 2. Project Objectives

- Monitor industrial process operating conditions.
- Detect unusual solvent consumption and potential solvent losses.
- Monitor extraction efficiency and production performance.
- Analyse simulated OT cybersecurity events.
- Correlate process anomalies with cybersecurity alerts.
- Support SOC investigation and incident triage.
- Provide explainable analytical findings.
- Generate engineering and security reports.
- Provide interactive operational dashboards.

## 5. Safety and Security Scope

This is an educational defensive monitoring project.

It uses synthetic industrial datasets and simulated security events.

The platform is designed to operate in a read-only analytical capacity.

It does not connect to live PLCs, SCADA systems, industrial networks
or production equipment.

It does not issue control commands or modify plant operations.

## 8. Disclaimer

Detection results are analytical indicators requiring human
verification. They do not independently establish the existence
of a real industrial fault, process failure or cyberattack.
